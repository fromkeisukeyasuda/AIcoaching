【RoleMate 試用のご案内】

このたびは、RoleMate の試用にご応募いただき、ありがとうございます。
RoleMate は、AI を相手に、コーチング・カウンセリングの「聴く力」を練習するアプリです。
使ってみての率直な感想が、改善のいちばんの助けになります。気軽にお試しください。

■ アプリのURL
https://rolemate-psi.vercel.app
スマホでも、パソコンでも使えます。ログインや登録は、要りません。

■ できること
・相談: コーチ（JO / YUKO）に、日常の悩みや考えごとを話して、気持ちを整理できます。
・練習: あなたがコーチ役になり、AI の相談者を相手に、面談を練習します。
　　　 「シナリオを作成」で、オリジナルの相談者（見た目は、HINA・MIKA・HARU から選択）も作れます。
　　　 行き詰まったときは、入力欄の電球ボタンで、次の一手のヒントが見られます。
・クイズ: 1問1答です。相談者の語りを読んで、4つの選択肢から選ぶと、すぐに○×と、正解にたどりつく考え方が出ます。
　　　 「主訴を見抜く」「見立てを考える」の2つのグループがあり、各100問です。難易度（初級・中級・上級・最上級、各25問）から選ぶか、全100問に挑戦できます。
　　　 まだ出ていない問題が優先して出るので、繰り返し使えます。
・記録: 練習のあとの振り返りシートが、あとから見返せます。
　　　 シートの中の「発言ごとの評価を作成する」を押すと、あなたの発言ごとに、点数と、良かった点・高めるポイントが見られます。
・マイページ: ヒントの表示と、音声読み上げの、オン・オフを切り替えられます。

■ スマホのホーム画面に追加する（アプリのように使えます）
・iPhone: Safari でURLを開き、画面下の共有ボタン（四角から矢印が出るマーク）を押して、「ホーム画面に追加」を選びます。
・Android: Chrome でURLを開き、右上のメニュー（点が3つ）から、「ホーム画面に追加」（または「アプリをインストール」）を選びます。

■ 使い方（はじめての方へ）
1. 画面下の「練習」を開き、相談者を選びます。（1回タップするだけで始まります）
2. 相談者が、最初に話しかけてくれます。コーチとして、聴いて、質問してみてください。
3. 数回やりとりしたら、右上の「終了」を押します。
　（やりとりが短すぎると、評価できません。目安は、5往復くらいです）
　「口頭試問と面接官評価をもらいますか？」と聞かれます。
　・「はい」: 面接官が、5つの質問（できたこと／改善点／主訴／見立て／今後の面談方針）をします。声か文字で答えると、面接官の評価が届きます。
　・「いいえ」: 振り返りシートだけが、1分ほどで表示されます。
4. あとから見返すときは、画面下の「記録」を開きます。

「相談」を試すときは、画面下の「相談」から、コーチを選んでください。はじめに、呼び名と年代を聞かれます（答えなくても、始められます）。

■ お願いとご注意
・名前、会社名、住所など、個人が特定できる情報は、入力しないでください。
・会話の内容は、返答や評価を作るために、AI のサービス（Google の Gemini）に送られます。
　読み上げの文章は、音声合成（VOICEVOX）にも送られます。
・開発の改善のため、使った回数（練習・相談の回数と、会話の往復数）を、匿名のIDで記録します。会話の内容は、記録しません。
　IDは、マイページで確認できます。感想をお送りいただくときに、添えていただけると助かります。
・記録は、お使いの端末のブラウザにだけ保存されます。別の端末とは、共有されません。
　ブラウザのデータを消すと、記録も消えます。マイページから、全データを削除することもできます。
・しばらく使っていない直後は、声が出るまで、10〜30秒ほどかかることがあります。
　最初の1回だけで、そのあとは、速くなります。
・声が出ないときは、端末の音量とマナーモードを確認し、マイページの「音声読み上げ」がオンか確認してください。
・音声入力（マイクのボタン）は、お使いのブラウザによっては、使えない場合があります。
・AI の返答や評価には、不自然な点や、誤りが含まれることがあります。練習の相手として、気軽にお使いください。
・試用中は、予告なく、内容を変更したり、一時的に使えなくなったりすることがあります。
